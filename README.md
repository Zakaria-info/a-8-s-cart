# Summer Essential

A polished Next.js product showcase with authentication, responsive design, and modern UI styling.

## Overview

This project demonstrates a small e-commerce-style storefront built with Next.js App Router, Tailwind CSS, DaisyUI, and `better-auth` for email/password and Google authentication.

## Key Features

- Authenticated login and signup flows
- Google social login integration
- Protected product detail pages for signed-in users
- Responsive homepage with animated hero section
- Product data sourced from a local JSON catalog

## Tech Stack

- Next.js
- React
- Tailwind CSS
- DaisyUI
- better-auth
- animate.css

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Create a `.env` file with the required environment variables.

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open the app in your browser at `http://localhost:3000`.

## Notes

- Make sure your Google OAuth credentials are configured correctly in the environment.
- Product details access is restricted to authenticated users.
